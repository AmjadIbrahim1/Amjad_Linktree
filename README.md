## 📌 Project Overview

**Amjad Linktree** is a personal **link-in-bio** page that centralizes all of Amjad Ibrahim's important links — social profiles, projects, and contact information — in one clean, shareable page.

---

## ✨ Key Features

- 🔗 **Centralized Links** – All important profiles in one place
- 📸 **Profile Photo** – Personal branding with `photo.jpg`
- ⚡ **Lightweight** – Single HTML file, no dependencies
- 📱 **Shareable** – Perfect for social media bios and resumes
